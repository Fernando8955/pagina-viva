# Página Viva

Site estático: livro 3D interativo de biologia (Lição 1: a célula), com demonstração automática e a proposta de piloto para escolas.

Publicado pelo Cloudflare Pages a partir da branch `main`. Para atualizar, edite o `index.html` e faça commit.

Endereço: https://pagina-viva.pages.dev

As mudanças enviadas para a branch `main` são publicadas automaticamente pelo Cloudflare Pages.
